# SMILEBAR 网页部署包

用于 GitHub Pages / Netlify / Vercel 等静态网页托管。

## GitHub Pages 快速部署

1. 新建一个公开仓库，例如 `smilebar`。
2. 上传本文件夹中的 `index.html` 和 `.nojekyll` 到仓库根目录。
3. 打开仓库 Settings → Pages。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，Folder 选择 `/root`，点击 Save。
6. 等待几分钟后访问 Pages 生成的网址。

## 手机使用

- iPhone：Safari 打开网址 → 分享 → 添加到主屏幕。
- 安卓：Chrome 打开网址 → 右上角菜单 → 添加到主屏幕。

注意：学习进度保存在当前浏览器本地。换设备时用软件里的“导出进度 / 导入进度”。
